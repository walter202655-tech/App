# Changelog - Aura100

All notable changes to Aura100 are documented here.

## [4.1.0] - 2026-11-26
### Added
- Quick navigation palette with search, keyboard navigation and shortcuts (Ctrl/Cmd + K or /).
- In-app changelog view and version history.
- Visible keyboard focus states for interactive controls.
### Improved
- Responsive header behavior on tablet and mobile.
- Reduced visual noise in compact layouts.
- Respect for operating-system reduced-motion preferences.

## [4.0.0] - 2026-11-26
### Added
- AI-assisted study calendar and daily vocabulary games.
- Cambridge B2 First preparation with guides, personalised practice, short mock tests and formative Predictive Notes.
- Exam question tutor, vocabulary review, progress notes and AI-assisted study summary.

## CEFR curriculum - 2026-11-27
- Added 50 modules across A1-C2, expanding the route from 15 to 65 lessons.
- Each module includes interactive exercises and answer explanations.

### Notes
- Study records remain stored according to the existing browser-local persistence behavior.
- AI features depend on the server-side AI configuration; implemented local fallbacks remain available.
